# メディアダウンローダー

URL を貼り付けるだけで、動画や音声を保存する Windows 用の GUI ツールです。
実際の処理は [yt-dlp](https://github.com/yt-dlp/yt-dlp) と [FFmpeg](https://ffmpeg.org/) が行い、
**この 2 つは初回起動時に自動で取得します**（同梱していません）。

**[→ ダウンロード（最新版）](https://github.com/johukku/media-downloader/releases/latest)**　|　
**[→ 使い方](https://johukku.pages.dev/)**

---

## 特徴

- **Python のインストール不要** — exe をダブルクリックするだけ
- **配布 ZIP は約 11 MB** — 重い部品は同梱せず、初回だけ取得する
- **ワンクリック** — 「動画（最高画質）」「音声のみ mp3 / wav」を選んで押すだけ
- **URL の自動貼り付け** — URL をコピーした状態で起動すると、そのまま入力欄に入る
- **まとめて処理** — 1 行に 1 つずつ URL を並べれば連続で処理、途中で中止も可能
- **部品を共有** — `Whisper 字幕作成ツール` など他の johukku 製ツールと
  同じ場所に FFmpeg を置くため、2 本目からは取得を省ける
- **字幕作成につなげられる** — 音声だけ抜き出して、そのまま
  [Whisper 字幕作成ツール](https://github.com/johukku/whisper-subtitle-tool)に読み込ませる

## 動作環境

| | |
|---|---|
| OS | Windows 10 / 11（64bit） |
| 必要なもの | インターネット接続 |
| 空き容量 | 約 300 MB（下記の部品を置くため） |

## 使い方

1. [Releases](https://github.com/johukku/media-downloader/releases/latest) から ZIP を取得して展開
2. `メディアダウンローダー.exe` をダブルクリック
3. 初回だけ、部品の取得を確認されるので「はい」を押す（数分かかります）
4. URL を貼り付け、形式を選んで「ダウンロード」

| 形式 | 用途 |
|---|---|
| 動画（最高画質） | いちばん良い画質で保存する |
| 動画（1080p まで） | ファイルが大きくなりすぎるのを避ける |
| 動画（720p まで・軽い） | 容量を節約する |
| 音声のみ（mp3） | 音楽・ラジオ・文字起こし用 |
| 音声のみ（wav・無圧縮） | 音質を落としたくないとき |

### 画質とファイル形式について

「最高画質」は、**そのサイトが配信している中で一番良いもの**を選びます。
画質そのものはサイト側の上限に左右されるため、サービスによっては
1080p や 720p が上限のこともあります。

mp4 に収まらない組み合わせ（VP9 + Opus など）のときは `.mkv` で保存されます。
Windows 11 の標準プレイヤーでは再生できますが、古い機器や編集ソフトで開きたい場合は
**「mp4 に統一する」**にチェックを入れてください。
yt-dlp 公式の `-t mp4` プリセットと同じ設定（h264 + aac を優先し、mp4 へ remux）で
取得するため、確実に mp4 になる代わりに画質が 1 段下がることがあります。

## 初回に取得される部品

| 名称 | 用途 | サイズ |
|---|---|---|
| yt-dlp | 動画の取得 | 約 17 MB |
| FFmpeg / ffprobe | 映像と音声の結合、mp3 / wav への変換 | 約 73 MB（展開後 約 180 MB） |

置き場所は `%LOCALAPPDATA%\johukku\bin` です。不要になったらフォルダごと削除してください。

同梱せずに毎回取得する形にしている理由:

- yt-dlp は動画サイト側の変更で頻繁に更新される。同梱すると、配り直すまで古いままになる
- FFmpeg は GPL なので、同梱して配ると**配布側にソース提供義務が生じる**。
  利用者の PC が公式の配布元から直接取得する形なら、こちらは何も再配布しない
- 他の johukku 製ツールと同じ場所を使うので、2 本目からは取得を省ける

## ファイル構成

| ファイル | 役割 |
|---|---|
| `downloader_app.py` | tkinter による GUI |
| `binaries.py` | yt-dlp / FFmpeg の取得・更新・共有フォルダの管理 |
| `ytdlp_runner.py` | yt-dlp の起動、進捗の読み取り、エラーの言い換え |
| `_build/make_exe.py` | 開発者用：exe と配布 ZIP の生成 |
| `_build/readme_exe.txt` | 配布物に同梱する説明書 |

## 開発者向け

実行時の依存ライブラリはありません（標準ライブラリと tkinter のみ）。

```
python _build\make_exe.py
```

ビルドには PyInstaller が要ります（入っていなければ自動で入れます）。
出来上がりは `_build/dist/` に置かれます（フォルダ約 27 MB、ZIP 約 11 MB）。

個々の部品は単体でも動かせます。

```
python binaries.py                   # 部品の取得だけを試す
python ytdlp_runner.py <URL> <保存先>  # GUI を通さずに 1 本落とす
```

## 注意

自分がアップロードした動画、配信のアーカイブ、権利者が許可しているコンテンツを
手元に保存するためのツールです。

権利者に無断で公開されているものをダウンロードする行為は、私的使用が目的であっても
違法となる場合があります。また、多くの動画サービスは利用規約でダウンロードを禁じています。
各サービスの規約とお住まいの国の法律を確認のうえ、自己責任でご利用ください。

動画サイト側の仕様変更で急に動かなくなることがあります。
その場合はまず画面右下の「yt-dlp を更新」をお試しください。
